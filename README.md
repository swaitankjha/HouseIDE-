# Smart IDE – ML-Powered Learning IDE

An intelligent IDE built to help students understand programming concepts through interactive learning. Instead of relying on external AI APIs, Smart IDE uses a **custom-trained Machine Learning model** to analyze code, provide explanations, detect errors, and visualize program flow.

## ✨ Features

- 💻 Monaco Editor integration
- 🧠 Custom-trained ML model for code analysis
- 📖 Beginner-friendly code explanations
- 🐞 Error detection and debugging assistance
- 📊 Flowchart visualization
- ⚡ Secure code execution

## 🛠️ Tech Stack

- React.js
- Node.js & Express
- Python
- Machine Learning
- Monaco Editor

## 🚀 Future Scope

- Multi-language support
